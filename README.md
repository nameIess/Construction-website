# 🏗️ Shiva Shakthi Constructions (WeBuild)

A modern, high-performance web portal for **Shiva Shakthi Constructions Private Limited**, re-engineered as a modern React SPA with an iOS / macOS frosted glassmorphism interface. ✨

## Features

- **macOS / iOS Glass Design System** 🪟: Frosted acrylic panels (`backdrop-blur`), subtle specular window highlights, macOS traffic lights, and dynamic Sonoma/Architectural wallpapers.
- **Hero Canvas Slider** 🎞️: High-definition project slideshow with ambient lighting, autoplay, manual controls, and quick certification badges.
- **About Us & Video Walkthrough** 🎬: Glass video player for on-site construction footage with custom controls and 4 live company stat counters (10+ years, 1500+ projects, 790+ clients, 450+ workers).
- **Comprehensive Services Showcase** 🛠️: 8 detailed core civil engineering services (Building Construction, House Renovation, Architecture Design, Material Supply, Construction Consultant, Interior Design, Building Maintenance, Building Renovation) with interactive specification modals.
- **Project Gallery & Lightbox** 🖼️: Filterable portfolio with categorized residential, commercial, renovation, and interior projects, with high-res Lightbox modal viewer and keyboard navigation.
- **Interactive Construction Cost Estimator** 💰: macOS widget-styled budget calculator based on Karnataka 2026 rates, built-up square footage, quality tier, modular woodwork, and BIM packages.
- **Client Testimonials Carousel** 💬: Reviews from Bangalore homeowners with 5-star rating badges and verified project tags.
- **Tiered Pricing Plans** 📋: Basic, Premium, and Ultimate retainers with monthly/yearly billing switches and instant checkout modal.
- **Contact & Bangalore Offices** 📍: Interactive Google Maps embed with Gokula (Mathikere) and Nelamangala branches, direct phone dialers, and validated contact inquiry form.
- **Technical Articles & Blogs** 📝: Civil engineering blogs with full reader modals.
- **Spotlight Search** 🔍: Fast `Cmd+K` / `Ctrl+K` search across services, projects, articles, and contacts.
- **Authentication** 🔑: Client portal sign-in and registration with demo account presets.
- **Contact Quick Info Drawer** 📲: Frosted slide-out sidebar matching the original info trigger.

## Tech Stack

- **Framework**: ⚛️ React 19 + TypeScript
- **Bundler**: 📦 Vite 6
- **Styling**: 🎨 Tailwind CSS v4 + Glassmorphism Backdrop Blur
- **Icons**: 💡 Lucide React
- **Port**: 🚀 3000 (`0.0.0.0`)

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Lint / type-check
npm run lint
```
